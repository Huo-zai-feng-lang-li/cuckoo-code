# 需求 123：提示词与工具回填的 4 万字输入上限防护

## 1. 背景

2026-11-16 多家媒体与用户实测：DeepSeek 因算力紧张，对 **App / 网页版** 普通用户限额：

- 单次输入文字上限降至 **约 4 万字**（不是 4 万 token，也**不是**模型上下文上限）；
- 超过 7 天不活跃的长对话不再支持接续；
- 新增每日对话额度。

**官方尚未发布正式公告**，细则与恢复时间未知；API 属独立资源池，不受影响（V4 API 仍为 1M 上下文）。

对本项目的直接影响：系统提示词是作为**首条用户消息**注入网页输入框，没有 system role。

| 场景 | 字符 | 相对 4 万字 |
|---|---:|---:|
| 本项目（改前实测） | 35,055 | 87.6%，仅余约 5,000 |
| 空项目 + 20KB CUCKOO.md | 41,430 | **已越线** |
| 再加 15KB 项目规则 | 56,498 | 大幅越线 |

同时，工具结果回填只有**单条 15,000** 上限，**多段汇总没有总上限**：3 段即 45,000+，再加用户草稿必然越线；且原截断只砍尾巴，错误栈/结论正好在尾部。

## 2. 目标

1. 任何 provider、任何项目，首条提示词 ≤ **36,000 字符**（留 4,000 余量），绝不依赖站点侧截断。
2. 工具结果回填单条消息 ≤ **39,000 字符**，多段总量按 **26,000** 均分。
3. 截断必须**可诊断、可自救**：保留头尾关键部分 + 明确提示 `read`/`slice`。
4. 工具契约（`api.d.ts` + `TOOL_SECTIONS`）**永不裁剪**，核心功能零破坏。
5. 普通项目（本项目/空项目）输出**与改前逐字一致**，不引入降质。

## 3. 改动清单

### 3.1 系统提示词总预算与降级阶梯（`src/session/prompt-builder.ts`）

- 总预算 `MAX_PROMPT_CHARS = 36000`；
- 分段上限：CUCKOO.md 6,000 / 规则 7,000 / 技能 4,000 / 子代理 1,200 / 记忆 2,500 / DSH 3,000；
- 超总预算时按 4 级降级（原样 → 压缩 → 最小 → 仅指针），每级只收紧可裁剪段，工具契约不动；
- 降级与最终长度写 `console.warn`，可诊断。

### 3.2 分段渲染的降级能力

- `buildUnscopedRulesSection(rules, { indexOnly })`：只输出「名字 + 路径」，正文按需 `read`；
- `buildSkillsSection(skills, { maxDesc | namesOnly })`：先压描述到 120 字符，再降为「名字 + 路径」；
- `buildAgentsSection(agents, { namesOnly })`：只列名字。

### 3.3 工具结果回填预算（`src/overlay/result-budget.ts` + `chat-input.ts`）

- 单条仍 15,000；多段按 `26,000 / 段数` 均分（最低 2,000）；
- 截断改**头尾保留**（65% 头 / 35% 尾），标记保留 `...[输出过长已截断]...` 原文，兼容系统提示词的「截断自救纪律」；
- 发送前硬上限 39,000，超过直接拦截并写 `lastSendError`，不发半截消息；
- 用户草稿优先保留，只收结果段。

### 3.4 输入框回填校验（`src/overlay/chat-input.ts`）

- DOM 回退（textarea / contentEditable）填完后读回长度，低于期望 0.5%（至少 16 字符）判定截断，取消发送；
- 初始提示遇到「未完整填入 / 消息超长」不再重试 30 次，直接终止并上报失败。

### 3.5 文档与幻觉诱饵修正

- `chatgpt.md` 不再指向不存在的 `systemPrompt.md`；
- `forgetMemory` 文档不再提示不存在的 `listMemories` 工具，改为「id 来自 remember 的返回值」；
- 清理 backlog / arch / prompts 中 `{{TOOLS_LIST}}` 的历史残留。

## 4. 不动的部分

- `api.d.ts` 不再做语义迁移或继续压缩（需求 122 已到格式压缩天花板）；
- `TOOLS_LIST` 不恢复；
- 自动压缩阈值（默认关闭、80 万）不在本需求范围；
- 工具执行器自身的输出上限（`task-manager` 256KB 等）不变。
